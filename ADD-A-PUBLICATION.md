# Add a publication using your browser

1. Open `_template/README.md` and copy its Markdown using the copy control or Raw view.
2. Return to the repository root. Select **Add file → Create new file**.
3. Enter a short folder name followed by `/README.md`, for example `inclusive-cities/README.md`. GitHub creates the folder automatically.
4. Paste the template, replace the prompts and delete unused fields. Use a short original summary and links to the original publication.
5. Select **Preview**, then **Commit changes** to main (or use a branch if your team wants review).
6. Add your publication and folder link to the table in the root README. Update its GitHub link in PUBLICATIONS.md, and publications.json if used by other tools.
7. Share the folder URL, such as `https://github.com/gdi-ucl/publications-and-reports/tree/main/inclusive-cities`.

You need Write access to add or edit files. If you cannot see the edit controls, ask the repository maintainer for access.

Every folder here is public. Use a separate private repository for restricted work. Do not upload participant information or research datasets, and do not assume you can republish a full PDF or illustration because it is available online.
